# 🎵 Desi Developer

> **Desi vibes for developers — discover awesome songs and enjoy a feature-rich music experience.**

**Desi Developer** is a modern, full-stack music platform designed especially for developers who love music with a desi touch. The project combines a clean user experience with secure authentication, music-related features, and a modern web architecture.

## 🚀 Features

* 🎧 Desi music experience
* 🔐 Secure user authentication
* 🔑 JWT-based authentication & authorization
* 🎵 Music management
* 👤 Admin functionality
* ⚡ Interactive and responsive frontend
* 🔗 RESTful APIs
* 🛡️ Spring Security integration
* 📱 Modern and responsive UI

## 🔐 Authentication

The backend uses **Spring Security** with **JWT (JSON Web Token)** authentication to provide secure login and protected API access.

The authentication system includes:

* Login
* JWT token generation
* JWT request filtering
* Admin authentication
* Protected endpoints

## ⚙️ Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/AnkitDev7/Desi-Developer.git
```

### 2. Start the Backend

Navigate to the backend directory:

```bash
cd Desi-Developer/Desi-Developer-Backend
```

Run the Spring Boot application:

```bash
./mvnw spring-boot:run
```

### 3. Start the Frontend

Open another terminal:

```bash
cd Desi-Developer/Desi-Developoper-Frontend
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```
